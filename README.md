# Corporate Site Demo

コーポレートサイト制作案件のデモ用リポジトリです。  
Figmaで提供されたデザインをもとにコーディングし、WordPressテーマとして納品した案件の静的HTML版です。

## 概要

| 項目     | 内容                                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 案件種別 | コーポレートサイト新規構築                                                                                                           |
| 担当範囲 | Figmaデザインのコーディング / WordPressテーマ化 / レスポンシブ対応 / アニメーション実装 / ローディング画面（本リポジトリでは未実装） |
| 納品形式 | WordPressテーマ（本リポジトリは静的HTMLデモ版）                                                                                      |

## 使用技術

- HTML / CSS
- JavaScript
- Bootstrap 5（レスポンシブ対応、グリッドシステム）
- WOW.js / animate.css（スクロールアニメーション）
- WordPress / PHP（納品物本体）

## 工夫した点

- 静的デザインに対してスクロールアニメーションを提案・実装し、ユーザー体験の向上を図った
- localStorageを用いた初回訪問時のみ表示されるローディング画面を実装
- 保守性を考慮した構造でWordPressテーマ化を実施
